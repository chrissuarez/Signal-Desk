# A strategic-keyword pre-filter gates Pass 2, and the Fit Score is removed from gating

Ingestion is a two-pass pipeline: Pass 1 extracts fields cheaply, Pass 2 deep-scrapes the full job description and runs the expensive LLM judgment. Full Strategic Analysis runs only on Pass 2, where the real job description exists — judging "the real job underneath the title" from a thin email snippet is exactly what we want to avoid.

The old gate into Pass 2 was `fitScore > 60`. In practice **almost nothing reached Pass 2**, because `fitScore` starts at 50 and only climbs on SEO-oriented keyword/industry/location matches — and the strategic target roles (Delivery Operations Lead, Resource Planning Lead) contain none of those keywords. The gate was simultaneously too high and calibrated to the wrong signal; gating the strategic funnel on the SEO score actively filtered *for* SEO roles, the opposite of the goal.

We decided the Pass-1 gate is a **Strategic Pre-filter**: pass if the title/snippet hits any Tier-1/Tier-2 strategic keyword or a target role-family title, AND no hard-exclude guardrail trips — a deliberately low, high-recall bar. The **legacy Fit Score is removed from gating entirely** (it survives only as the later Practical-fit component input). Net effect is an inversion of the funnel: it widens for strategic roles (which now actually flow through) and narrows for SEO-only roles (previously the only things that passed). The accepted cost: high recall means some non-strategic roles get an expensive Pass-2 analysis, and keyword presence is a blunt instrument that will let through false positives for the LLM to reject downstream.
